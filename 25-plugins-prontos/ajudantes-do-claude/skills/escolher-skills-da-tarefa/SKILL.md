# Escolher as skills da tarefa

Responda em português.

1. Se a tarefa não veio na mensagem, pergunte qual é.
2. Olhe as skills instaladas (a lista de skills disponíveis nesta conversa).
3. Escolha só as que servem para essa tarefa. Poucas e certas: cada skill carregada gasta limite.
4. Diga quais vai usar e por quê, em uma linha cada.
5. Faça a tarefa usando essas skills.

Se nenhuma servir, diga isso e faça sem skill.
